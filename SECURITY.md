# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of **agentshield-python** (`agentshield-defense` PyPI SDK) seriously.

## Supported Versions

| Version | Supported | Minimum Runtime | Response Target |
| :--- | :---: | :---: | :---: |
| **>= 0.2.2** | Active | Python >= 3.9 | Critical & High: < 24 Hours |
| < 0.2.2 | End-of-Life | — | Upgrade to >= 0.2.2 immediately |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed security vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/agentshield-python/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] agentshield-defense (agentshield-python)`

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
